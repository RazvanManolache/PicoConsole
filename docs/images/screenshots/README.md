# Screenshot sources and credits

These are software captures, not photographs of the LCD. They illustrate the
launcher and individual game engines; they are not a claim that the current UF2
has been tested on physical hardware. PNG files are copied without alteration.
Capture hashes and source references are recorded in `provenance.json`.

| Files | Origin and terms |
|---|---|
| `menu-all.png`, `menu-favorites.png`, `menu-recent.png` | PicoConsole 0.6 shared launcher renderer, captured by `tools/check_library_host.py`. The sample favorites/history are desktop fixtures. Launcher code is GPLv3; the background preview derivatives retain the corresponding game component terms recorded in `assets/menu-previews/provenance.json`. |
| `sokoban.png` | Current curated PicoLibSDK Sokoban engine, captured by `tools/capture_native_previews.py`. Original drawing/tiles credited to Miroslav Nemecek under the retained Unlicense declaration; the shown puzzle is original PicoConsole work under GPLv3. No removed upstream puzzle collection is shown. |
